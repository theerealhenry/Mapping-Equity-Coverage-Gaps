# Risk Register

A dynamic risk register, per `PROJECT_BLUEPRINT.md`'s documentation section: each entry carries an
ID, description, probability, impact, a probability x impact score, mitigation, status, an owner,
and a last-reviewed date — not a static table filled once. Seeded at Stage 4 with the six risks
already identified across Stages 1-3's own real findings and audits (transcription of already-done
work into its intended final home, not speculative future content); new risks are added as they're
identified in later stages.
